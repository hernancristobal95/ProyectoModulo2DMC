# ProyectoModulo2DMC

### 1. Descripción del proyecto

Realizar un Análisis Exploratorio de Datos sobre clientes de una empresa de telecomunicaciones para identificar patrones relacionados con el abandono de clientes (Churn). Se utilizarán herramientas de Python y Streamlit para analizar y visualizar los principales resultados.
